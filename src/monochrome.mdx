# Monochrome

## Introduction

Monochrome is a web component library built with Stencil, providing fast, standards-based components that work in any framework or with no framework at all.


### Key Features

- **Framework-agnostic** - Components work in React, Vue, Angular, or vanilla JavaScript
- **Standards-based** - Built on Web Components APIs (Custom Elements, Shadow DOM)
- **TypeScript support** - Full type safety and IntelliSense
- **Lazy loading** - Components load on-demand for optimal performance
- **Small bundle size** - Minimal runtime overhead

### Getting Started

Components in this library can be consumed in two ways:

1. **Lazy Loading** - Import the loader script for automatic, on-demand component loading
2. **Standalone** - Import individual components directly into your build

Browse the component documentation in the sidebar to see examples and API details for each component.
